# Changelog

All notable changes to Keystrand are documented here.

## [1.0.0] — 2026-06-01

### Added
- **Live Pulse** status bar item showing today's focus time and streak in real time.
- **Analytics Dashboard** webview with weekly bar chart, language donut, heatmap, streak tracker, AI ratio gauge, and gentle insights.
- **Strand card generator** — daily / weekly / monthly PNG export at 1200×630 with four themes: Dark, Neon, Ocean, Forest.
- **AI-assisted code ratio** estimation via large-insertion detection. Labeled as an estimate.
- **Activity heatmap** (day-of-week × hour) for all-time patterns.
- Local-only JSON storage via VS Code global storage API.
- `Keystrand: Export My Data (JSON)` command.
- `Keystrand: Reset All Data` command (with confirmation dialog).
- First-run welcome notification.
- Configuration: idle threshold, AI line threshold, Strand theme, status bar toggle, language/project tracking toggles.
