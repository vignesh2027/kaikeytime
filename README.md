# Keystrand — Privacy-First Coding Analytics

> Track your coding activity **100% locally**. Beautiful shareable Strand cards. No account. No API key. No cloud. Your data never leaves your machine.

---

## Why Keystrand?

Every other coding analytics tool (WakaTime, Code::Stats, etc.) requires you to create an account and routes your data through their servers. Keystrand is different — it stores everything in a single JSON file on your machine. Zero network requests with your data. Zero sign-up. Zero surveillance.

---

## Features

### 🔒 100% Local & Private
- All data stored in VS Code's global storage as a single JSON file.
- No telemetry. No accounts. No API keys.
- One-click **Export My Data** (JSON) and **Reset All Data** options.

### ⚡ Live Pulse Status Bar
A subtle status bar item shows your today's focus time and current streak in real time while you code. Click it to open the dashboard.

```
$(clock) 2h 14m · 🔥7d
```

### 📊 Beautiful Dashboard
Rich, interactive dashboard with:
- **Today's headline stats** — focus time, lines added, files touched
- **Weekly activity bar chart** — see your rhythm over the past 7 days
- **Language breakdown** — animated donut chart of time per language
- **Activity heatmap** — GitHub-style, day-of-week × hour-of-day (all-time)
- **Project breakdown** — time and lines per workspace
- **Streak tracker** — current and all-time longest streak
- **Gentle insights** — factual, positive observations about your coding patterns

### 🤖 AI-Assisted Code Ratio *(Unique Feature)*
Keystrand estimates what percentage of your code was likely AI-generated by detecting **large single-shot insertions** — multi-line blocks inserted in one edit event, characteristic of GitHub Copilot, Cursor, and other AI tools. Displayed as an approximate percentage, clearly labeled as an estimate.

> **This is a flagship, unique feature** — no other local coding analytics tool tracks this.

### 🎴 Strand Cards — Shareable Visual Summaries
Generate a stunning, screenshot-ready **Strand card** with a single command:

**Command Palette → `Keystrand: Generate Strand Card`**

- Choose **Daily**, **Weekly**, or **Monthly** summary.
- Pick from 4 gorgeous themes: **Dark** (default), **Neon** (cyberpunk), **Ocean**, **Forest**.
- The card renders at **1200 × 630px** — perfect for LinkedIn, X (Twitter), or Discord.
- Export as PNG directly to your Desktop.
- Small tasteful "made with Keystrand" mark.

Example card headline:
```
This Week: 18h 42m focused · 62% TypeScript · 14,203 lines · 9-day streak · 28% AI-assisted
```

## What It Tracks

| Metric | Details |
|--------|---------|
| Active coding time | Time with active edits; idle after configurable threshold |
| Idle detection | Default 120s; configurable 30–600s |
| Language time | Per `languageId`, time and lines |
| Project time | Per workspace folder |
| File activity | Files touched, unique count |
| Lines added / removed | From document change events |
| AI-assisted lines | Estimate via large single-shot insertions |
| Hourly heatmap | Best focus hours by time of day |
| Day-of-week patterns | Most productive days |
| Coding streaks | Consecutive active days |

## Getting Started

### Prerequisites
- VS Code 1.80.0 or newer
- Node.js 18+ (for building from source)

### Install from Marketplace
Search **"Keystrand"** in the VS Code Extensions panel and click Install.

### Build from Source
```bash
git clone https://github.com/keystrand/keystrand
cd keystrand
npm install
npm run compile
```
Then press **F5** in VS Code to launch the Extension Development Host.

### First Use
Once installed, Keystrand starts automatically. Look for the `$(clock)` item in your status bar. Open the dashboard anytime via:
- Clicking the status bar item
- **Command Palette** → `Keystrand: Open Dashboard`

---

## Commands

| Command | Description |
|---------|-------------|
| `Keystrand: Open Dashboard` | Open the analytics dashboard |
| `Keystrand: Generate Strand Card` | Create a shareable Strand card (daily/weekly/monthly) |
| `Keystrand: Export My Data (JSON)` | Open your raw data as a JSON document |
| `Keystrand: Reset All Data` | Permanently clear all tracked data |

---

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `keystrand.idleThresholdSeconds` | `120` | Seconds before considered idle (30–600) |
| `keystrand.strandTheme` | `"dark"` | Card theme: `dark`, `neon`, `ocean`, `forest` |
| `keystrand.trackLanguages` | `true` | Track time per language |
| `keystrand.trackProjects` | `true` | Track time per project |
| `keystrand.showStatusBar` | `true` | Show live Pulse status bar item |
| `keystrand.aiDetectionThreshold` | `5` | Min lines in one insertion to flag as AI |

## Privacy

Keystrand makes **zero network requests with your data**. Full stop. Your coding data is stored in:

```
~/.config/Code/User/globalStorage/keystrand.keystrand/keystrand-data.json
```

(path varies by OS and VS Code flavor)

You can inspect, copy, or delete this file at any time. The "Export My Data" command opens it as a JSON document. The "Reset All Data" command wipes it entirely.
